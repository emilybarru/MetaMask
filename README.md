# MetaMask

MetaMask implements decentralized cryptographic protocols, facilitating real-time transaction processing via a secure, multi-account client wallet.

MetaMask is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaMask.git`
2. `cd MetaMask`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure MetaMask, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
